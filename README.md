# Mascot Newsbot — ข่าวด่วนพร้อมร่างโพสต์ ส่งเข้า LINE (เฟส 1)

ทุก 30 นาที ระบบจะอ่านข่าวจาก RSS ของสำนักข่าวไทยและกรมอุตุนิยมวิทยา ให้ Claude จัดกลุ่มข่าวเรื่องเดียวกัน ให้คะแนนความด่วน แล้ววิเคราะห์ข่าวที่ด่วนจริงว่า **เกิดอะไร สาเหตุ เมื่อไหร่ ที่ไหน ใครได้รับผลกระทบ** พร้อมร่างแคปชันในน้ำเสียงของ mascot ส่งเข้า LINE ของคุณ คุณตรวจ แล้วกดค้างที่แคปชันเพื่อคัดลอกไปโพสต์เอง

**ระบบไม่โพสต์อะไรเองทั้งสิ้น** ทุกโพสต์ผ่านการตรวจของคุณ

## สิ่งที่จะได้รับใน LINE

| ข้อความ | ส่งเมื่อ | หน้าตา |
| --- | --- | --- |
| แจ้งข่าวด่วน | ข่าวคะแนน ≥ 70 (ตั้งได้) | การ์ดสรุป: เกิดอะไร / สาเหตุ / เมื่อไหร่ / ที่ไหน / ผลกระทบ / สิ่งที่ยังไม่รู้ / ไอเดียการ์ดรูป / คำเตือน + ปุ่มเปิดข่าวต้นทาง แล้วตามด้วยข้อความแคปชัน + แฮชแท็ก + เครดิตที่มา พร้อมคัดลอก |
| สรุปข่าวรอบวัน | 08:00, 12:00, 18:00 (ตั้งได้) | รายการข่าวน่าสนใจที่ไม่ถึงขั้นด่วน เรียงตามคะแนน แตะเพื่ออ่านข่าวต้นทาง |

ช่วง 00:00–06:00 จะไม่แจ้ง ยกเว้นข่าวคะแนน 90 ขึ้นไป ข่าวที่พักไว้จะถูกส่งในรอบแรกหลัง 06:00

## ติดตั้ง (ประมาณ 30 นาที ทำครั้งเดียว)

ต้องเตรียม 3 อย่าง: **Claude API key**, **LINE Official Account**, **บัญชี GitHub** (ฟรี ใช้เป็นที่รันระบบอัตโนมัติ ไม่ต้องมีเซิร์ฟเวอร์)

### ขั้นที่ 1 — Claude API key

1. สมัครที่ [platform.claude.com](https://platform.claude.com)
2. เมนู **Billing** → เติมเครดิต (เริ่ม 5–10 ดอลลาร์ก็พอทดลอง) และแนะนำให้ตั้ง **spend limit** รายเดือนไว้กันค่าใช้จ่ายเกิน
3. เมนู **API Keys** → **Create Key** → คัดลอกเก็บไว้ (ขึ้นต้นด้วย `sk-ant-`)

### ขั้นที่ 2 — LINE (ช่องทางรับแจ้งเตือน)

> LINE Notify ปิดบริการไปแล้วตั้งแต่ 31 มี.ค. 2025 ระบบนี้จึงใช้ LINE Messaging API ผ่าน LINE Official Account แทน ชื่อเมนูอาจต่างจากนี้เล็กน้อย

1. สร้าง LINE Official Account ฟรีที่ [manager.line.biz](https://manager.line.biz) (ใช้เป็นบัญชีส่งแจ้งเตือนส่วนตัว ไม่ต้องประกาศให้ใครรู้)
2. ใน LINE OA Manager: **ตั้งค่า → Messaging API → เปิดใช้งาน Messaging API** แล้วเลือกหรือสร้าง Provider
3. เข้า [developers.line.biz/console](https://developers.line.biz/console) → เลือก Provider → เลือก Channel ของ OA นี้
   - แท็บ **Basic settings** → เลื่อนลงหา **Your user ID** → คัดลอก (ขึ้นต้นด้วย `U`) นี่คือ `LINE_USER_ID`
   - แท็บ **Messaging API** → **Channel access token (long-lived)** → กด **Issue** → คัดลอก นี่คือ `LINE_CHANNEL_ACCESS_TOKEN`
   - แท็บ **Messaging API** → สแกน QR code ด้วยมือถือเพื่อ **เพิ่ม OA เป็นเพื่อน** (ถ้าไม่เพิ่มเพื่อน ข้อความจะส่งไม่ถึง)
4. (แนะนำ) ใน LINE OA Manager ปิดข้อความตอบกลับอัตโนมัติและข้อความทักทาย

### ขั้นที่ 3 — เอาระบบขึ้น GitHub ให้รันเองทุก 30 นาที

1. สมัคร/ล็อกอิน [github.com](https://github.com) → **New repository** → ตั้งชื่อ เช่น `mascot-newsbot` → เลือก **Private** → Create
2. กด **uploading an existing file** → แตกไฟล์ zip แล้วลากไฟล์และโฟลเดอร์ทั้งหมดเข้าไป → **Commit changes**
   - โฟลเดอร์ `.github` อาจถูกซ่อนในเครื่อง Mac/Windows ถ้าอัปโหลดไม่ติด ให้กด **Add file → Create new file** ตั้งชื่อ `.github/workflows/newsbot.yml` แล้ววางเนื้อหาจากไฟล์เดียวกันในโฟลเดอร์ที่แตกไว้
3. ใน repo: **Settings → Secrets and variables → Actions → New repository secret** เพิ่ม 3 ตัว:

   | Name | Value |
   | --- | --- |
   | `ANTHROPIC_API_KEY` | API key จากขั้นที่ 1 |
   | `LINE_CHANNEL_ACCESS_TOKEN` | token จากขั้นที่ 2 |
   | `LINE_USER_ID` | user ID จากขั้นที่ 2 |

4. แท็บ **Actions** → กดยืนยันเปิดใช้ workflows (ถ้ามีถาม) → เลือก **Mascot Newsbot** → **Run workflow** → command = **test-line** → Run
   ภายใน 1–2 นาที LINE ของคุณควรได้ข่าวตัวอย่าง ถ้าได้ แปลว่า LINE ตั้งค่าถูกแล้ว
5. **Run workflow** อีกครั้ง → command = **check-sources** → เปิดดู log ว่าแหล่งข่าวไหนใช้ได้ (✓)
6. **Run workflow** → command = **run** เพื่อรันรอบแรก

เสร็จแล้ว หลังจากนี้ระบบรันเองทุก 30 นาที ดูประวัติการรันได้ที่แท็บ Actions ถ้ารอบไหน AI หรือ LINE มีปัญหา รอบนั้นจะขึ้นสีแดงและ GitHub จะส่งอีเมลแจ้ง

**หมายเหตุเรื่อง GitHub Actions**
- repo แบบ Private ได้นาทีฟรีเดือนละ 2,000 นาที รันทุก 30 นาทีใช้ราว 1,500 นาที/เดือน จึง **ไม่ควรตั้งถี่กว่า 30 นาที** บน GitHub ถ้าอยากได้ทุก 20 นาทีให้รันบน VPS (ด้านล่าง)
- รอบที่ตั้งเวลาไว้อาจเลื่อนไปบ้างไม่กี่นาทีช่วงที่ GitHub คนใช้เยอะ
- ไม่แนะนำ repo แบบ Public: GitHub จะปิด workflow ที่ตั้งเวลาไว้อัตโนมัติถ้า repo ไม่มีความเคลื่อนไหว 60 วัน

## ปรับแต่ง (`config.yaml`)

แก้ไฟล์ `config.yaml` ใน GitHub ได้เลย (กดไอคอนดินสอ) ไม่ต้องแตะโค้ด

| ตั้งค่า | ค่าเริ่มต้น | ใช้ทำอะไร |
| --- | --- | --- |
| `mascot.name / personality / voice / sign_off` | น้องข่าว | ชื่อ บุคลิก น้ำเสียง คำลงท้าย ที่ AI ใช้เขียนแคปชัน **ควรแก้ให้เป็น mascot ของคุณก่อนใช้จริง** |
| `alerts.threshold` | 70 | คะแนนขั้นต่ำที่แจ้งด่วน ถ้าแจ้งถี่ไปให้ขึ้นเป็น 75–80 |
| `alerts.max_per_run` | 3 | แจ้งด่วนได้กี่เรื่องต่อรอบ |
| `alerts.quiet_hours` | [0, 6] | ช่วงไม่รบกวน ใส่ `[]` ถ้าอยากรับตลอด 24 ชม. |
| `alerts.quiet_override` | 90 | ข่าวคะแนนเท่านี้ขึ้นไป แจ้งแม้ช่วงไม่รบกวน |
| `digest.hours` | [8, 12, 18] | เวลาส่งสรุปรอบวัน |
| `digest.min_score` / `max_items` | 35 / 8 | ข่าวแบบไหนเข้าสรุป และสรุปละกี่เรื่อง |
| `ai.analysis_model` | claude-sonnet-5-5 | โมเดลที่วิเคราะห์และเขียนแคปชัน |
| `sources` | 9 แหล่ง | เพิ่ม/ลด/ปิดแหล่งข่าว RSS แล้วรัน check-sources เพื่อตรวจ |

### เกณฑ์คะแนนความด่วน
- **90–100** อันตรายหรือผลกระทบใหญ่ต่อคนไทย "ตอนนี้" เช่น เตือนภัยพิบัติ แผ่นดินไหวที่รู้สึกได้ในไทย เหตุมีผู้เสียชีวิตมาก มาตรการรัฐที่มีผลทันที
- **70–89** ข่าวสำคัญที่คนจะพูดถึงวันนี้ การตัดสินใจของรัฐที่กระทบประชาชนโดยตรง
- **40–69** ข่าวน่าสนใจทั่วไป (เข้าสรุปรอบวัน)
- **0–39** ข่าวประจำวัน ข่าวเฉพาะกลุ่ม ข่าว PR/โฆษณาแฝง (ข่าว PR ไม่ถูกแจ้งเลย)

| Claude Sonnet 5.5 วิเคราะห์เฉพาะข่าวด่วน ($2 / $10 ต่อล้าน token) ราว 0.05 ดอลลาร์ต่อข่าว | ราว 3–8 ดอลลาร์ ถ้าวันละ 2–5 ข่าว |

## รันบนเครื่องตัวเองหรือ VPS (ทางเลือก)

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # แล้วแก้ใส่ key จริง

python -m newsbot check-sources   # ตรวจแหล่งข่าว
python -m newsbot test-line       # ส่งข้อความทดสอบเข้า LINE
python -m newsbot run --dry-run   # รันจริงกับ AI แต่แสดงผลบนจอแทนการส่ง LINE
python -m newsbot run             # รันจริง
python -m unittest -v             # ทดสอบระบบแบบออฟไลน์ (ไม่ใช้ key)
```

ตั้ง cron ให้รันทุก 20 นาที (`crontab -e`):

```
*/20 * * * * cd /path/to/mascot-newsbot && .venv/bin/python -m newsbot run >> logs/newsbot.log 2>&1
```

(สร้างโฟลเดอร์ `logs` ก่อน: `mkdir logs`)

## ข้อควรรู้

- **ลิขสิทธิ์:** ระบบเก็บลิงก์รูปจากข่าวไว้อ้างอิงเท่านั้น ไม่ได้แนบรูปมาให้โพสต์ ใช้การ์ดรูปของเพจเองตาม "ไอเดียการ์ดรูป" ที่ AI แนะนำ แคปชันถูกสั่งให้เขียนใหม่ทั้งหมดและใส่เครดิตที่มาเสมอ
- **ตรวจก่อนโพสต์ทุกครั้ง:** AI ถูกสั่งให้ใช้เฉพาะข้อมูลในข่าวและเขียนว่า "ยังไม่มีข้อมูล" เมื่อไม่รู้ แต่ยังผิดพลาดได้ โดยเฉพาะข่าวที่มีแหล่งเดียว (การ์ดจะขึ้นคำเตือน)
- **ข่าวต่อเนื่อง:** ถ้ามีข่าวใหม่ของเรื่องที่แจ้งไปแล้ว ระบบจะรวมเข้าเรื่องเดิมโดยไม่แจ้งซ้ำ
- **แหล่งข่าว:** ตรวจแล้วว่าฟีดใช้ได้ ณ วันที่สร้างระบบ (ต.ค. 2026) ถ้าวันหนึ่งฟีดไหนเสีย ระบบจะข้ามแหล่งนั้นไปและแสดงใน log ว่า "ฟีดมีปัญหา"
- **ข้อมูลที่เก็บ:** ประวัติข่าวที่เห็นแล้วเก็บใน `data/state.json` (บน GitHub เก็บใน Actions cache) ลบทิ้งได้ ระบบจะเริ่มใหม่โดยอ่านเฉพาะข่าว 6 ชั่วโมงล่าสุด
