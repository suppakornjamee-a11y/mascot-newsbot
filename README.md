# Mascot Newsbot — ข่าวด่วนพร้อมร่างโพสต์ ส่งเข้า LINE (เฟส 1)

ทุก 30 นาที ระบบจะอ่านข่าวจาก RSS ของสำนักข่าวไทยและกรมอุตุนิยมวิทยา ให้ AI (ค่าเริ่มต้นคือ Gemini ใช้ฟรี) จัดกลุ่มข่าวเรื่องเดียวกัน ให้คะแนนความด่วน แล้ววิเคราะห์ข่าวที่ด่วนจริงว่า **เกิดอะไร สาเหตุ เมื่อไหร่ ที่ไหน ใครได้รับผลกระทบ** จากนั้นเรียบเรียงเป็นโพสต์ข่าวในน้ำเสียงของ mascot ตรวจทานข้อเท็จจริงอีกรอบ และทำรูปการ์ดข่าวที่มีภาพพื้นหลังเกี่ยวกับข่าว ส่งเข้า LINE ของคุณ คุณตรวจ แล้วกดค้างที่โพสต์เพื่อคัดลอกไปโพสต์เอง

**ระบบไม่โพสต์อะไรเองทั้งสิ้น** ทุกโพสต์ผ่านการตรวจของคุณ

### ทีม AI ในระบบ

ข่าวด่วนแต่ละเรื่องผ่าน AI ทีละขั้น เหมือนกองบรรณาธิการ:

| ขั้น | หน้าที่ | ไฟล์ |
| --- | --- | --- |
| 1. คัดกรอง | จัดกลุ่มข่าวเรื่องเดียวกัน ให้คะแนนความด่วน | `newsbot/ai.py` |
| 2. วิเคราะห์ | สรุปข้อเท็จจริง: เกิดอะไร สาเหตุ เมื่อไหร่ ที่ไหน ผลกระทบ สิ่งที่ยังไม่รู้ | `newsbot/ai.py` |
| 3. บรรณาธิการเรียบเรียง | เขียนโพสต์ข่าว 2-3 ย่อหน้า หัวข้อและพาดหัวบนการ์ด แฮชแท็ก อารมณ์ของน้องปิ๊ง และคำค้นภาพประกอบ | `newsbot/editor.py` |
| 4. ผู้ตรวจทาน | เทียบโพสต์กับข่าวต้นทาง ลบหรือแก้ตัวเลข ชื่อ และข้ออ้างที่ไม่มีในแหล่งข่าว แล้วบอกว่าแก้อะไรไป | `newsbot/editor.py` |
| 5. บรรณาธิการภาพ | ให้ AI วาดภาพประกอบตามเนื้อข่าวผ่าน Cloudflare แล้วให้ AI อีกตัวตรวจภาพ ถ้าวาดไม่ได้จะค้นภาพถ่ายจาก Pixabay แทน จากนั้นตัดต่อเป็นการ์ด | `newsbot/art.py`, `newsbot/card.py` |

ขั้น 3-5 ทำเฉพาะข่าวที่กำลังจะส่งแจ้งเตือน ข่าวที่พักไว้ช่วงไม่รบกวนจะยังไม่ถูกเรียบเรียงจนกว่าจะส่งจริง

## สิ่งที่จะได้รับใน LINE

| ข้อความ | ส่งเมื่อ | หน้าตา |
| --- | --- | --- |
| แจ้งข่าวด่วน | ข่าวคะแนน ≥ 70 (ตั้งได้) | การ์ดสรุป: เกิดอะไร / สาเหตุ / เมื่อไหร่ / ที่ไหน / ผลกระทบ / สิ่งที่ยังไม่รู้ / ผลตรวจทาน / เครดิตภาพ / คำเตือน + ปุ่มเปิดข่าวต้นทาง ตามด้วยรูปการ์ดข่าว แล้วปิดด้วยโพสต์ที่เรียบเรียงแล้ว + แฮชแท็ก + เครดิตที่มาและภาพ พร้อมคัดลอก |
| สรุปข่าวรอบวัน | 08:00, 12:00, 18:00 (ตั้งได้) | รายการข่าวน่าสนใจที่ไม่ถึงขั้นด่วน เรียงตามคะแนน แตะเพื่ออ่านข่าวต้นทาง |

ช่วง 00:00–06:00 จะไม่แจ้ง ยกเว้นข่าวคะแนน 90 ขึ้นไป ข่าวที่พักไว้จะถูกส่งในรอบแรกหลัง 06:00

## ติดตั้ง (ประมาณ 30 นาที ทำครั้งเดียว)

ต้องเตรียม 5 อย่าง ฟรีทั้งหมด: **Gemini API key**, **LINE Official Account**, **Cloudflare** (AI วาดภาพประกอบ), **Pixabay API key** (ภาพถ่ายสำรอง), **บัญชี GitHub** (ใช้เป็นที่รันระบบอัตโนมัติ ไม่ต้องมีเซิร์ฟเวอร์)

### ขั้นที่ 1 — Gemini API key (ฟรี)

1. เข้า [aistudio.google.com](https://aistudio.google.com) แล้วล็อกอินด้วยบัญชี Google
2. กด **Get API key** → **Create API key** → คัดลอกเก็บไว้
3. ไม่ต้องใส่บัตรเครดิต และ**อย่าเปิด billing** ในโปรเจกต์นี้ ถ้าไม่เปิด จะไม่มีทางถูกเก็บเงิน ถ้าใช้เกินโควตาฟรี รอบนั้นจะแค่ทำงานไม่สำเร็จแล้วลองใหม่รอบถัดไป

> ข้อแลกเปลี่ยนของ free tier: Google อาจนำข้อมูลที่ส่งเข้าไปใช้ปรับปรุงผลิตภัณฑ์ ระบบนี้ส่งเฉพาะข่าวสาธารณะกับคำอธิบายบุคลิก mascot จึงไม่มีข้อมูลส่วนตัวรั่ว

### ขั้นที่ 2 — LINE (ช่องทางรับแจ้งเตือน)

> LINE Notify ปิดบริการไปแล้วตั้งแต่ 31 มี.ค. 2025 ระบบนี้จึงใช้ LINE Messaging API ผ่าน LINE Official Account แทน ชื่อเมนูอาจต่างจากนี้เล็กน้อย

1. สร้าง LINE Official Account ฟรีที่ [manager.line.biz](https://manager.line.biz) (ใช้เป็นบัญชีส่งแจ้งเตือนส่วนตัว ไม่ต้องประกาศให้ใครรู้)
2. ใน LINE OA Manager: **ตั้งค่า → Messaging API → เปิดใช้งาน Messaging API** แล้วเลือกหรือสร้าง Provider
3. เข้า [developers.line.biz/console](https://developers.line.biz/console) → เลือก Provider → เลือก Channel ของ OA นี้
   - แท็บ **Basic settings** → เลื่อนลงหา **Your user ID** → คัดลอก (ขึ้นต้นด้วย `U`) นี่คือ `LINE_USER_ID`
   - แท็บ **Messaging API** → **Channel access token (long-lived)** → กด **Issue** → คัดลอก นี่คือ `LINE_CHANNEL_ACCESS_TOKEN`
   - แท็บ **Messaging API** → สแกน QR code ด้วยมือถือเพื่อ **เพิ่ม OA เป็นเพื่อน** (ถ้าไม่เพิ่มเพื่อน ข้อความจะส่งไม่ถึง)
4. (แนะนำ) ใน LINE OA Manager ปิดข้อความตอบกลับอัตโนมัติและข้อความทักทาย

### ขั้นที่ 3 — Cloudflare Workers AI (ฟรี สำหรับ AI วาดภาพประกอบข่าว)

1. สมัครบัญชีฟรีที่ [dash.cloudflare.com](https://dash.cloudflare.com/sign-up) ไม่ต้องมีเว็บไซต์และไม่ต้องใส่บัตรเครดิต
2. ในหน้า dashboard เปิดเมนู **Workers AI** แล้วกด **Use REST API**
3. ใต้หัวข้อ **Get Account ID** คัดลอก **Account ID** นี่คือ `CLOUDFLARE_ACCOUNT_ID`
4. กด **Create a Workers AI API Token** ตรวจข้อมูลที่กรอกไว้ให้ แล้วกด **Create API Token** → **Copy API Token** นี่คือ `CLOUDFLARE_API_TOKEN`
5. ใช้ฟรีวันละ 10,000 neurons รีเซ็ต 07:00 น. เวลาไทย โมเดล FLUX.1 schnell ที่ระบบใช้กินราว 77 neurons ต่อภาพ จึงวาดได้ราว 130 ภาพต่อวัน ถ้าใช้เกิน ระบบจะใช้ภาพถ่ายจาก Pixabay แทนจนกว่าโควตาจะรีเซ็ต ไม่มีการเก็บเงิน

ถ้ายังไม่ใส่ 2 ค่านี้ ระบบยังทำงานปกติ แค่จะใช้ภาพถ่ายจาก Pixabay แทนภาพที่ AI วาด

### ขั้นที่ 4 — Pixabay API key (ฟรี สำหรับภาพถ่ายสำรอง)

1. สมัครบัญชีฟรีที่ [pixabay.com](https://pixabay.com/accounts/register/) แล้วยืนยันอีเมล
2. ล็อกอินแล้วเปิด [pixabay.com/api/docs](https://pixabay.com/api/docs/) เลื่อนลงไปที่หัวข้อ **Parameters** ช่อง `key` จะแสดง API key ของคุณ → คัดลอก
3. ใช้ฟรี ได้ 100 ครั้งต่อนาที ระบบใช้ไม่เกิน 3 ครั้งต่อข่าวด่วน และเก็บผลค้นหาไว้ 24 ชั่วโมงตามเงื่อนไขของ Pixabay

ใช้เมื่อ AI วาดภาพไม่ได้ หรือตั้ง `card.background: photo` ถ้าไม่มีทั้ง Cloudflare และ Pixabay ระบบยังทำงานปกติ แค่การ์ดจะเป็นพื้นสีเรียบแบบเดิม และ GitHub Actions จะขึ้นคำเตือนสีเหลือง

> ถ้ามี Pexels API key อยู่แล้ว ใส่เป็น secret `PEXELS_API_KEY` เพิ่มได้ ระบบจะใช้ Pexels เป็นแหล่งภาพสำรองเมื่อ Pixabay หาภาพไม่พอ (Pexels หยุดออก key ใหม่ชั่วคราวตั้งแต่ปี 2026)

### ขั้นที่ 5 — เอาระบบขึ้น GitHub ให้รันเองทุก 30 นาที

1. สมัคร/ล็อกอิน [github.com](https://github.com) → **New repository** → ตั้งชื่อ เช่น `mascot-newsbot` → เลือก **Private** → Create
2. กด **uploading an existing file** → แตกไฟล์ zip แล้วลากไฟล์และโฟลเดอร์ทั้งหมดเข้าไป → **Commit changes**
   - โฟลเดอร์ `.github` อาจถูกซ่อนในเครื่อง Mac/Windows ถ้าอัปโหลดไม่ติด ให้กด **Add file → Create new file** ตั้งชื่อ `.github/workflows/newsbot.yml` แล้ววางเนื้อหาจากไฟล์เดียวกันในโฟลเดอร์ที่แตกไว้
3. ใน repo: **Settings → Secrets and variables → Actions → New repository secret** เพิ่ม 6 ตัว:

   | Name | Value |
   | --- | --- |
   | `GEMINI_API_KEY` | API key จากขั้นที่ 1 |
   | `LINE_CHANNEL_ACCESS_TOKEN` | token จากขั้นที่ 2 |
   | `LINE_USER_ID` | user ID จากขั้นที่ 2 |
   | `CLOUDFLARE_ACCOUNT_ID` | Account ID จากขั้นที่ 3 |
   | `CLOUDFLARE_API_TOKEN` | API token จากขั้นที่ 3 |
   | `PIXABAY_API_KEY` | key จากขั้นที่ 4 |

4. แท็บ **Actions** → กดยืนยันเปิดใช้ workflows (ถ้ามีถาม) → เลือก **Mascot Newsbot** → **Run workflow** → command = **test-line** → Run
   ภายใน 1–2 นาที LINE ของคุณควรได้ข่าวตัวอย่าง ถ้าได้ แปลว่า LINE ตั้งค่าถูกแล้ว ถ้ารูปการ์ดมีภาพฝนตกเป็นพื้นหลัง แปลว่าตั้งค่าภาพถูกแล้ว ถ้าการ์ดเขียนว่า "ภาพประกอบสร้างด้วย AI" แปลว่า Cloudflare ใช้ได้
5. **Run workflow** อีกครั้ง → command = **check-sources** → เปิดดู log ว่าแหล่งข่าวไหนใช้ได้ (✓)
6. **Run workflow** → command = **run** เพื่อรันรอบแรก

เสร็จแล้ว หลังจากนี้ระบบรันเองทุก 30 นาที ดูประวัติการรันได้ที่แท็บ Actions ถ้ารอบไหน AI หรือ LINE มีปัญหา รอบนั้นจะขึ้นสีแดงและ GitHub จะส่งอีเมลแจ้ง ยกเว้นโควตาฟรีรายวันของ Gemini หมด ซึ่งจะขึ้นแค่คำเตือนสีเหลือง ระบบจะหยุดเรียก AI ในรอบนั้นทันที และทำข่าวที่ค้างต่อหลังโควตารีเซ็ต แต่ละรอบทำงานไม่เกินราว 10 นาที ข่าวที่ทำไม่ทันจะต่อในรอบหน้า

**หมายเหตุเรื่อง GitHub Actions**
- repo แบบ Private ได้นาทีฟรีเดือนละ 2,000 นาที รันทุก 30 นาทีใช้ราว 1,500 นาที/เดือน จึง **ไม่ควรตั้งถี่กว่า 30 นาที** บน GitHub ถ้าอยากได้ทุก 20 นาทีให้รันบน VPS (ด้านล่าง)
- รอบที่ตั้งเวลาไว้อาจเลื่อนไปบ้างไม่กี่นาทีช่วงที่ GitHub คนใช้เยอะ
- ไม่แนะนำ repo แบบ Public: GitHub จะปิด workflow ที่ตั้งเวลาไว้อัตโนมัติถ้า repo ไม่มีความเคลื่อนไหว 60 วัน

## รูปโพสต์ (การ์ดข่าวน้องปิ๊ง)

ทุกข่าวด่วนที่ส่งเข้า LINE จะมีรูปโพสต์ขนาด 1080×1080 แนบมาด้วย กดค้างที่รูปใน LINE เพื่อบันทึกแล้วเอาไปโพสต์ได้เลย การ์ดมีส่วนประกอบดังนี้

- **ภาพพื้นหลังที่เกี่ยวกับข่าว** บรรณาธิการเรียบเรียงเขียนคำบรรยายภาพ แล้วให้ AI วาดภาพประกอบแบบภาพวาดบรรณาธิการผ่าน Cloudflare จากนั้น AI อีกตัวตรวจว่าภาพไม่มีตัวอักษรมั่ว ใบหน้าบิดเบี้ยว ความรุนแรง หรือดูเหมือนภาพข่าวจริง ถ้าไม่ผ่านจะวาดใหม่อีกครั้ง ถ้ายังไม่ผ่านจะค้นภาพถ่ายจาก Pixabay แทน ภาพถูกครอปเต็มการ์ดและไล่เงาเข้มด้านล่างให้อ่านตัวหนังสือได้
- **หัวข้อข่าว** ป้ายสีส้มเหนือพาดหัว เช่น "สังคม · สันติภาพ" และ **พาดหัว** ตัวใหญ่สีขาว
- **น้องปิ๊ง** มุมขวาล่าง มีขอบขาวแบบสติกเกอร์ให้เด่นบนทุกภาพ มี 3 อารมณ์: ยิ้มสดใส (ข่าวทั่วไป), ตื่นเต้น (ข่าวดี), จริงจัง (เตือนภัย ข่าวร้าย) ข่าวภัยพิบัติ อาชญากรรม และข่าวอ่อนไหวจะได้หน้าจริงจังเสมอ
- **วันที่ ที่มา และเครดิตภาพ** บรรทัดล่าง ภาพที่ AI วาดจะเขียนว่า "ภาพประกอบสร้างด้วย AI" ภาพถ่ายจะเขียนว่า "ภาพประกอบ: ชื่อช่างภาพ / Pixabay" เครดิตเดียวกันจะต่อท้ายโพสต์ให้ด้วย

AI ถูกสั่งไม่ให้วาดหรือเลือกภาพที่ทำให้เข้าใจผิดว่าเป็นภาพจากเหตุการณ์จริง เช่น ไม่วาดบุคคลจริงหรือสถานที่จริงให้เหมือนจริง ไม่เลือกภาพที่หน้าคนชัดเป็นจุดเด่น ไม่เลือกภาพคนยิ้มกับข่าวร้าย และไม่เลือกภาพสถานที่ดังแห่งอื่นที่ไม่ใช่สถานที่ในข่าว ถ้าไม่มีภาพไหนเหมาะ การ์ดจะใช้พื้นสีเรียบแบบเดิมให้อัตโนมัติ ข่าวยังส่งตามปกติ

ตั้งค่าภาพพื้นหลังได้ที่ `card.background`:

| ค่า | ภาพพื้นหลัง | ค่าใช้จ่าย |
| --- | --- | --- |
| `ai` (ค่าเริ่มต้น) | AI วาดภาพประกอบตามเนื้อข่าว ใช้ภาพถ่ายจาก Pixabay เมื่อวาดไม่ได้ | ฟรี ต้องมี `CLOUDFLARE_ACCOUNT_ID` และ `CLOUDFLARE_API_TOKEN` ถ้าเปลี่ยน `card.image_provider` เป็น `gemini` จะเสียเงิน |
| `photo` | ภาพถ่ายฟรีจาก Pixabay และ Pexels ถ้ามี key | ฟรี ต้องมี `PIXABAY_API_KEY` |
| `plain` | พื้นสีเรียบแบบเดิม พร้อมรายละเอียดข่าว 1-2 ประโยค | ฟรี |

- **ฟอนต์** Mitr กับ IBM Plex Sans Thai (ใช้ฟรีภายใต้ OFL) อยู่ใน `assets/fonts`
- **ภาพน้องปิ๊ง** อยู่ใน `assets/mascot` ถ้าแก้ตัวละคร ให้แก้ `tools/build_mascot.py` แล้วรัน `python tools/build_mascot.py`
- **โลโก้เพจ** วางไฟล์ `assets/logo.png` (พื้นหลังใส) จะแสดงที่มุมขวาบน หรือใส่ชื่อเพจใน `card.page_name`
- **ที่เก็บรูป** รูปจะถูกเก็บไว้ใน branch `cards` ของ repo นี้ repo ต้องเป็น **Public** LINE ถึงจะเปิดรูปได้ ถ้าสร้างรูปไม่ได้ ข่าวยังส่งตามปกติ แค่ไม่มีรูปแนบ
- ไม่ใช้รูปจากสำนักข่าว เพราะติดลิขสิทธิ์ และทำให้แพลตฟอร์มมองว่าไม่ใช่คอนเทนต์ต้นฉบับ ภาพจาก Pixabay และ Pexels ใช้และตัดต่อได้ฟรีตามสัญญาอนุญาตของแต่ละเว็บ

## ปรับแต่ง (`config.yaml`)

แก้ไฟล์ `config.yaml` ใน GitHub ได้เลย (กดไอคอนดินสอ) ไม่ต้องแตะโค้ด

| ตั้งค่า | ค่าเริ่มต้น | ใช้ทำอะไร |
| --- | --- | --- |
| `mascot.name / personality / voice / sign_off` | น้องปิ๊ง | ชื่อ บุคลิก น้ำเสียง ที่ AI ใช้เขียนแคปชัน (ตาม character sheet ของน้องปิ๊ง) |
| `card.size` / `card.page_name` | 1080×1080 / ว่าง | ขนาดรูปโพสต์ และชื่อเพจมุมขวาบน |
| `card.background` | ai | ภาพพื้นหลังการ์ด: `ai` ให้ AI วาด, `photo` ภาพถ่ายฟรีจาก Pixabay, `plain` พื้นสีเรียบ |
| `card.image_provider` / `card.image_model` | cloudflare / ว่าง | ผู้ให้บริการ AI วาดภาพ และโมเดล ว่าง = FLUX.1 schnell ลองโมเดลอื่นของ Cloudflare ได้ เช่น `@cf/black-forest-labs/flux-2-klein-4b` คุณภาพดีกว่าแต่วาดฟรีได้ราววันละ 90 ภาพ |
| `card.ai_pick` | true | ให้ AI ตรวจภาพที่วาด หรือเลือกภาพถ่ายที่เข้ากับข่าว ถ้าปิด จะใช้ภาพแรกที่ได้ (ประหยัด AI 1 ครั้งต่อข่าว แต่ภาพอาจไม่เหมาะ) |
| `editor.fact_check` | true | ให้ AI ตรวจโพสต์เทียบกับข่าวต้นทางก่อนส่ง ถ้าปิด จะประหยัด AI 1 ครั้งต่อข่าว |
| `ai.gemini.review_model` | gemini-3.5-flash-lite | โมเดลที่ตรวจทานและเลือกภาพ แยกจากตัววิเคราะห์เพื่อไม่ให้กินโควตาฟรีของตัววิเคราะห์ |
| `alerts.threshold` | 70 | คะแนนขั้นต่ำที่แจ้งด่วน ถ้าแจ้งถี่ไปให้ขึ้นเป็น 75–80 |
| `alerts.max_per_run` | 3 | แจ้งด่วนได้กี่เรื่องต่อรอบ |
| `alerts.quiet_hours` | [0, 6] | ช่วงไม่รบกวน ใส่ `[]` ถ้าอยากรับตลอด 24 ชม. |
| `alerts.quiet_override` | 90 | ข่าวคะแนนเท่านี้ขึ้นไป แจ้งแม้ช่วงไม่รบกวน |
| `digest.hours` | [8, 12, 18] | เวลาส่งสรุปรอบวัน |
| `digest.min_score` / `max_items` | 35 / 8 | ข่าวแบบไหนเข้าสรุป และสรุปละกี่เรื่อง |
| `ai.provider` | gemini | `gemini` = ฟรี, `claude` = เสียเงินตามการใช้ (ดูด้านล่าง) |
| `ai.gemini.analysis_model` | gemini-3.8-flash | โมเดลที่วิเคราะห์และเขียนแคปชัน |
| `sources` | 9 แหล่ง | เพิ่ม/ลด/ปิดแหล่งข่าว RSS แล้วรัน check-sources เพื่อตรวจ |

### เกณฑ์คะแนนความด่วน
- **90–100** อันตรายหรือผลกระทบใหญ่ต่อคนไทย "ตอนนี้" เช่น เตือนภัยพิบัติ แผ่นดินไหวที่รู้สึกได้ในไทย เหตุมีผู้เสียชีวิตมาก มาตรการรัฐที่มีผลทันที
- **70–89** ข่าวสำคัญที่คนจะพูดถึงวันนี้ การตัดสินใจของรัฐที่กระทบประชาชนโดยตรง
- **40–69** ข่าวน่าสนใจทั่วไป (เข้าสรุปรอบวัน)
- **0–39** ข่าวประจำวัน ข่าวเฉพาะกลุ่ม ข่าว PR/โฆษณาแฝง (ข่าว PR ไม่ถูกแจ้งเลย)

| Pixabay API | ฟรี ใช้ไม่เกิน 3 ครั้งต่อข่าวด่วน เมื่อ AI วาดไม่ได้ (โควตา 100 ครั้ง/นาที) |
| GitHub Actions (repo private) | ฟรี (อยู่ในโควตา 2,000 นาที/เดือน) |
| LINE Messaging API | ใช้ราว 150–250 ข้อความ/เดือน ตรวจว่าอยู่ในโควตาฟรีของแพ็กเกจคุณที่ LINE OA Manager |

ถ้าวันหนึ่ง Google ปรับลดโควตาฟรีจนไม่พอ ระบบจะแจ้ง error ใน GitHub Actions ทางแก้คือลดจำนวนแหล่งข่าว ขึ้น `alerts.threshold` ให้วิเคราะห์น้อยลง หรือปิด `editor.fact_check` กับ `card.ai_pick`

### ถ้าอยากเปลี่ยนไปใช้ Claude (เสียเงิน)

แก้ `ai.provider: claude` ใน `config.yaml` แล้วเพิ่ม secret `ANTHROPIC_API_KEY` (เติมเครดิตที่ [platform.claude.com](https://platform.claude.com)) ค่าใช้จ่ายเดิมประมาณ 5–13 ดอลลาร์/เดือน ขั้นเรียบเรียง ตรวจทาน และเลือกภาพจะเพิ่มค่าใช้จ่ายตามจำนวนข่าวด่วน ทุกขั้นใช้ Claude ได้ ยกเว้น `card.background: ai` ที่ต้องใช้ Gemini เสมอ

## รันบนเครื่องตัวเองหรือ VPS (ทางเลือก)

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # แล้วแก้ใส่ key จริง

python -m newsbot check-sources   # ตรวจแหล่งข่าว
python -m newsbot test-line       # ส่งข้อความทดสอบเข้า LINE (รูปจะถูกบันทึกไว้ใน out/cards)
python -m newsbot demo            # ส่งข่าวเด่น 24 ชม. เป็นตัวอย่าง
python -m newsbot run --dry-run   # รันจริงกับ AI แต่แสดงผลบนจอแทนการส่ง LINE
python -m newsbot run             # รันจริง
python -m unittest -v             # ทดสอบระบบแบบออฟไลน์ (ไม่ใช้ key)
```

ตั้ง cron ให้รันทุก 20 นาที (`crontab -e`):

```
*/20 * * * * cd /path/to/mascot-newsbot && .venv/bin/python -m newsbot run >> logs/newsbot.log 2>&1
```

(สร้างโฟลเดอร์ `logs` ก่อน: `mkdir logs`)

## ข้อควรรู้

- **ลิขสิทธิ์:** ระบบไม่ใช้รูปจากสำนักข่าว ภาพพื้นหลังมาจาก Pixabay หรือ Pexels ที่อนุญาตให้ตัดต่อและใช้เชิงพาณิชย์ได้ฟรี และมีเครดิตช่างภาพทั้งบนการ์ดและท้ายโพสต์ โพสต์ถูกสั่งให้เขียนใหม่ทั้งหมดและใส่เครดิตที่มาเสมอ
- **ภาพประกอบไม่ใช่ภาพเหตุการณ์จริง:** การ์ดเขียนว่า "ภาพประกอบ" หรือ "ภาพประกอบสร้างด้วย AI" เสมอ ภาพที่ AI วาดไม่ใช่สถานที่หรือบุคคลจริง ถ้าภาพที่ได้อาจทำให้คนเข้าใจผิด ให้เปลี่ยน `card.background` เป็น `plain` หรือทำการ์ดเอง
- **สิทธิ์ใช้ภาพที่ AI วาด:** FLUX.1 schnell เปิดให้ใช้เชิงพาณิชย์ภายใต้ Apache 2.0 ถ้าเปลี่ยนโมเดล ให้ตรวจเงื่อนไขของโมเดลนั้นก่อน
- **ตรวจก่อนโพสต์ทุกครั้ง:** AI ถูกสั่งให้ใช้เฉพาะข้อมูลในข่าวและเขียนว่า "ยังไม่มีข้อมูล" เมื่อไม่รู้ และมีผู้ตรวจทานอีกรอบ แต่ยังผิดพลาดได้ โดยเฉพาะข่าวที่มีแหล่งเดียว (การ์ดจะขึ้นคำเตือน) ถ้าผู้ตรวจทานแก้อะไร การ์ดใน LINE จะบอกว่าแก้ไปกี่จุดและแก้อะไร
- **ข่าวต่อเนื่อง:** ถ้ามีข่าวใหม่ของเรื่องที่แจ้งไปแล้ว ระบบจะรวมเข้าเรื่องเดิมโดยไม่แจ้งซ้ำ
- **แหล่งข่าว:** ตรวจแล้วว่าฟีดใช้ได้ ณ วันที่สร้างระบบ (ต.ค. 2026) ถ้าวันหนึ่งฟีดไหนเสีย ระบบจะข้ามแหล่งนั้นไปและแสดงใน log ว่า "ฟีดมีปัญหา"
- **ข้อมูลที่เก็บ:** ประวัติข่าวที่เห็นแล้วเก็บใน `data/state.json` (บน GitHub เก็บใน Actions cache) ลบทิ้งได้ ระบบจะเริ่มใหม่โดยอ่านเฉพาะข่าว 6 ชั่วโมงล่าสุด
